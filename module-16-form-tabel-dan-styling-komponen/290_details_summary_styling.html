Pertanyaan Umum (FAQ)

Apakah CSS ini membutuhkan JavaScript?
Tidak sama sekali! Elemen <details> dan <summary> memiliki fungsi toggle bawaan dari spesifikasi HTML5, dan CSS bertugas mengatur gayanya.
Bagaimana cara menghilangkan segitiga default?
Gunakan list-style: none; pada summary untuk Firefox, serta summary::-webkit-details-marker { display: none; } untuk Chrome/Safari.
